# QuickOcr

一款完全离线的 Android 屏幕文字提取工具：随时框选屏幕上的一块区域，把里面的文字识别出来并复制到剪贴板，全程不离开当前应用。

适合阅读扫描版 PDF、图片笔记、截图、网页长图时，快速取出其中一小段文字。

## 功能

- **框选 / 全屏识别**：任意界面呼出入口 → 屏幕冻结 → L 型标尺拖框选区或点「全屏识别」→ 识别；结果页支持直接**重选区域**微调，无需重新截屏
- **三种结果操作模式**：
  - **逐字选择（默认）**：支持直接划选、点起点再点终点、拖动蓝色水滴手柄以及 `起点 ◀ / ▶`、`◀ / ▶ 终点` 单字微调
  - **按行勾选**：逐行勾选、长按单行直接复制、一键全选 / 复制全部
  - **快捷编辑**：直接在结果面板内修正个别错别字后再复制
- **完全离线**：PP-OCRv5 端侧模型，支持 720p 标准 / 1080p 高精度档位切换，自适应留白扩边与视觉行聚类排序，不联网、不上传任何画面
- **三种入口，可同时使用**
  - 悬浮球：自动贴边吸附与位置记忆，闲置 2.5 秒半透明缩小停靠，点一下即截
  - 通知栏：按需开启；关闭后配合无障碍截屏**彻底不占用通知栏**
  - 下拉磁贴：在应用内点「下拉控制中心磁贴」，经系统确认后加入控制中心
- **每行换行开关 & 内存最近识别**：自由控制多行拼接是否插入换行；纯内存暂存最近 5 条记录（退出即清空），误关面板也可找回
- **不切界面**：关闭悬浮层即回到原应用

## 安装

从 [Releases](https://github.com/MiaoMiaoChongChong/QuickOcr/releases) 下载 `QuickOcr-v1.1.0.apk` 安装。

- 需要 **Android 11（API 30）及以上**
- 首次使用请在应用内完成授权（见下）

## 权限说明

| 权限 | 用途 |
| --- | --- |
| 无障碍服务（推荐） | 调用系统截屏接口获取画面。开关由系统保存，一次开启长期有效，关闭通知栏入口后零通知占用 |
| 悬浮窗 | 显示悬浮球、框选层与逐字选字面板 |
| 录屏（备用） | 未开启无障碍时作为备用截屏方式（Android 14+ 系统要求投影期间保留一条通知） |
| 通知 | 仅在开启「通知栏入口」或使用录屏备用通道时使用 |

无障碍服务**不读取界面文字、不监听输入、不联网**，只用于在主动触发时截取屏幕图像。

小米 / HyperOS 设备若提示「受限制的设置」，请先到「应用信息 → 高级设置 → 允许受限制的设置」，再开启无障碍服务。

## 使用

1. 打开应用，在「权限与截屏通道」开启**无障碍截屏**与**悬浮窗权限**
2. 在「识别入口」按需开启悬浮球、通知栏入口或下拉磁贴
3. 在任意界面呼出入口 → 拖框或点「全屏识别」→ 逐字划选 / 按行勾选 / 编辑 → 复制即回原应用

## 从源码构建

- JDK 17、Android SDK（compileSdk 36）、Gradle 8.9
- `gradle assembleRelease`，产物在 `app/build/outputs/apk/release/`
- 识别模型位于 `app/src/main/assets`，随 APK 打包

## 隐私

应用不声明网络权限，不含统计、广告或上传逻辑；识别模型与所有数据都留在设备上。
