# QuickOcr

一款完全离线的 Android 屏幕文字提取工具：随时框选屏幕上的一块区域，把里面的文字识别出来并复制到剪贴板，全程不离开当前应用。

适合阅读扫描版 PDF、图片笔记、截图、网页长图时，快速取出其中一小段文字。

## 功能

- **框选识别**：任意界面呼出入口 → 屏幕冻结 → 拖动四边四角框住目标区域 → 识别 → 勾选需要的行 → 复制
- **完全离线**：PP-OCRv5 端侧模型，不联网、不上传任何画面
- **三种入口，可同时使用**
  - 悬浮球：点一下即截
  - 通知栏：常驻通知里的「截屏框选」
  - 下拉磁贴：在应用内点「添加下拉磁贴」，经系统确认后加入控制中心
- **每行换行开关**：识别结果默认每行换行；阅读连续文章时可在设置或结果面板关掉，避免页面折行被当成段落
- **结果可筛选**：逐行勾选、长按单行直接复制、一键全选 / 复制全部
- **不切界面**：关闭框选层即回到原应用

## 安装

从 [Releases](../../releases) 下载 `QuickOcr-v1.0.0.apk` 安装。

- 需要 **Android 11（API 30）及以上**
- 首次使用请在应用内完成授权（见下）

## 权限说明

| 权限 | 用途 |
| --- | --- |
| 无障碍服务（推荐） | 调用系统截屏接口获取画面。开关由系统保存，一次开启长期有效 |
| 悬浮窗 | 显示悬浮球与框选层 |
| 录屏（备用） | 未开启无障碍时，作为获取画面的备用方式 |
| 通知 | 常驻「截屏框选」入口 |

无障碍服务**不读取界面文字、不监听输入、不联网**，只用于在主动触发时截取屏幕图像。

小米 / HyperOS 设备若提示「受限制的设置」，请先到「应用信息 → 高级设置 → 允许受限制的设置」，再开启无障碍服务。

## 使用

1. 打开应用，在「一、授权」完成授权，在「二、识别入口」选择需要的入口
2. 在任意界面点悬浮球 / 通知栏「截屏框选」/ 下拉磁贴
3. 拖框选中文字 → 点「识别」→ 勾选行 → 复制

## 从源码构建

- JDK 17、Android SDK（compileSdk 36）、Gradle 8.9
- `gradle assembleRelease`，产物在 `app/build/outputs/apk/release/`
- 识别模型位于 `app/src/main/assets`，随 APK 打包

## 隐私

应用不声明网络权限，不含统计、广告或上传逻辑；识别模型与所有数据都留在设备上。
